# Ny Prisma – Naturfagskasser 7.–9. klasse

Færdig hjemmeside med 472 originalark, temakasser, fælles indkøb og redigerbare priser. Seneste ændring: vakuumpumpe 3.000 kr. ekskl. moms. Standardbudget med alle kasser: 66.966 kr. ekskl. moms.

## Sådan lægger du siden på GitHub Pages

1. Pak ZIP-filen ud på din computer.
2. Log ind på https://github.com og opret et nyt repository, fx `naturfagskasser`.
3. Vælg **Add file → Upload files**. Træk **indholdet** af mappen `NyPrisma-GitHub` ind: `index.html`, `README.md` og hele mappen `assets`. Upload ikke ZIP-filen eller den yderste mappe. Filen `.nojekyll` kan også medtages, hvis den vises; hjemmesiden bruger ingen Jekyll-funktioner.
4. Klik **Commit changes**. `index.html` skal nu ligge direkte i repositoryets rod.
5. Åbn **Settings → Pages**.
6. Under **Source** vælger du **Deploy from a branch**. Vælg **main** og **/(root)**, og klik **Save**.
7. Når siden er klar, viser GitHub Pages et link, typisk `https://DIT-BRUGERNAVN.github.io/naturfagskasser/`. Det er dette link, du sender til kolleger.

GitHub Pages-tilgængelighed afhænger af konto og repositoryets synlighed. Vejledning: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Brug lokalt

Åbn `index.html` i Chrome eller Edge. Behold mappen `assets` ved siden af filen. Billederne er fordelt på seks filer for at gøre upload via GitHubs hjemmeside lettere. Der kræves ingen installation eller bygning.

## Priser og valg

Alle aftalte priser og køb-fravalg er med. Priser, lager og valg kan ændres i programmet. Fællesudstyr tælles kun én gang i det samlede budget. Hver browser gemmer sine egne ændringer; de bliver ikke automatisk delt med andre. Brug programmets **Gem valg som fil** og indlæsning til at overføre en opsætning.

Materialekoblinger er delvist registreret. Grundposter uden fuld kobling bevares konservativt, som beskrevet i programmet. Samleposterne er brugerangivne budgetbeløb, ikke indhentede produkttilbud.

## Originalark

Pakken indeholder originale Ny Prisma-kopiark fra de leverede filer. De oprindelige rettigheder tilhører rettighedshaverne; pakken giver ikke i sig selv tilladelse til offentliggørelse af arkene. Brug en delingsform, der passer til skolens rettigheder.
